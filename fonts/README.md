# Fontovi

Naslov "Kavica" koristi font **Delight Coffee**.

Datoteku koju si skinuo (`.ttf` ili `.otf`) stavi ovdje s jednim od ovih imena:

- `DelightCoffee.ttf`
- `DelightCoffee.otf`
- `DelightCoffee.woff2` (najmanja, ako je pretvoriš)

Dok je nema, naslov se prikazuje u fontu **Fredoka** (vrlo sličan, besplatan).

besplatni fontovi su samo za osobnu uporabu. Za vaš privatni hobi projekt to je obično u redu,
ali ako ne smije, ostavi Fredoku.
